# Orkeon Studio documentation

Orkeon Studio is the family of graphical and terminal front-ends over the `orkeon` CLI. The framework itself, its CLI and its documentation live in the [Orkeon repository](https://github.com/Orkeon/orkeon/blob/main/docs/INDEX.md).

| Page | What it covers |
|---|---|
| [Architecture](architecture/studio.md) | The four projects, the shared core, the three front-ends, how Studio drives the `orkeon` CLI. |
| [README](../README.md) | What Studio is, installing it from a release, prerequisites, building, running and installing from source. |
| [Release](reference/release.md) | The release artifacts, how the release workflow builds and smokes them, how to cut a release. |
| [Contributing](../CONTRIBUTING.md) | Branching, build and test commands, conventions. |
| [Changelog](../CHANGELOG.md) | Changes, breaking ones first. |

Studio needs the `orkeon` CLI: see the [Orkeon CLI reference](https://github.com/Orkeon/orkeon/blob/main/docs/reference/cli.md) and the [configuration reference](https://github.com/Orkeon/orkeon/blob/main/docs/reference/configuration.md) for the `appsettings.json` Studio edits.
