# Documentation d'Orkeon Studio

Orkeon Studio est la famille de frontaux graphiques et terminal au-dessus de la CLI `orkeon`. Le framework, sa CLI et leur documentation vivent dans le [dépôt Orkeon](https://github.com/Orkeon/orkeon/blob/main/docs/fr/INDEX.md).

| Page | Contenu |
|---|---|
| [Architecture](architecture/studio.md) | Les quatre projets, le cœur partagé, les trois frontaux, la façon dont Studio pilote la CLI `orkeon`. |
| [README](../../README.fr.md) | Ce qu'est Studio, son installation depuis une release, les prérequis, la construction, le lancement et l'installation depuis les sources. |
| [Release](reference/release.md) | Les artefacts de release, la façon dont le workflow de release les construit et les teste, comment publier une release. |
| [Contribuer](../../CONTRIBUTING.fr.md) | Branches, commandes de build et de test, conventions. |
| [Journal des changements](../../CHANGELOG.md) | Les changements, les ruptures d'abord. |

Studio a besoin de la CLI `orkeon` : voir la [référence de la CLI Orkeon](https://github.com/Orkeon/orkeon/blob/main/docs/fr/reference/cli.md) et la [référence de configuration](https://github.com/Orkeon/orkeon/blob/main/docs/fr/reference/configuration.md) pour l'`appsettings.json` que Studio édite.
